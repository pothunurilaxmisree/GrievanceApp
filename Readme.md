# Grievance App for Pilgrims

A web application designed to help pilgrims report and resolve grievances efficiently.

## Features
✅ Report issues related to:
   - 🎟️ Tickets
   - 🔒 Lockers
   - 🅿️ Parking
   - 🚾 Sanitation
   - & More...
✅ Real-time tracking of complaints  
✅ User-friendly interface with Angular  
✅ Secure backend powered by Java & MySQL  

## Tech Stack
- **Frontend:** Angular  
- **Backend:** Java (Spring Boot)  
- **Database:** MySQL
